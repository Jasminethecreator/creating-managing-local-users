# Creating and Managing Local Users

## Objective

Create and manage local Windows user accounts and verify that newly created accounts appear correctly in Local Users and Groups.

## Tools & Environment

* Windows 11
* Local Users and Groups
* Windows user account management

## Steps Performed

1. Opened **Local Users and Groups** in Windows.
2. Created a new local user account for **Sam Smith**.
3. Configured the account information.
4. Verified that the newly created account appeared in the local user list.
